# scaleway_dataorchestrator_workflow_start (Action)

Starts a Scaleway Data Orchestrator workflow definition run.

Set `wait_for_completion` to `true` to block until the run reaches a terminal state
(fails the action if the run does not succeed).


## Example Usage

```terraform
resource "scaleway_dataorchestrator_workflow" "main" {
  name         = "example-workflow"
  description  = "Managed by Terraform"
  region       = "fr-par"
  version_name = "v1-0-0"

  workflow_dsl = <<-EOT
    document:
      dsl: 1.0.3
      namespace: example
      name: example-workflow
      version: 1.0.0
    do:
      - setColor:
          set:
            color: blue
  EOT

  lifecycle {
    action_trigger {
      events  = [after_create]
      actions = [action.scaleway_dataorchestrator_workflow_start.main]
    }
  }
}

action "scaleway_dataorchestrator_workflow_start" "main" {
  config {
    workflow_definition_id = scaleway_dataorchestrator_workflow.main.id
    wait_for_completion    = true
  }
}
```

### Required

- `workflow_definition_id` (String) ID of the workflow definition to start. Plain UUID or regional ID.
