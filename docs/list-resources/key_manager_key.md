# Resource: scaleway_key_manager_key

Lists Scaleway Key Manager Keys across regions and projects.

For more information, see [the main documentation](https://www.scaleway.com/en/docs/key-manager/concepts/).

## Example Usage

```terraform
# List all keys across all regions and projects
list "scaleway_key_manager_key" "all" {
  provider = scaleway

  config {
    regions     = ["*"]
    project_ids = ["*"]
  }
}
```

```terraform
# List keys filtered by name
list "scaleway_key_manager_key" "by_name" {
  provider = scaleway

  config {
    name = "my-key"
  }
}
```

```terraform
# List keys in specific projects
list "scaleway_key_manager_key" "by_projects" {
  provider = scaleway

  config {
    project_ids = [
      "11111111-1111-1111-1111-111111111111",
      "22222222-2222-2222-2222-222222222222",
    ]
  }
}
```

```terraform
# List keys filtered by protection level
list "scaleway_key_manager_key" "by_protection_level" {
  provider = scaleway

  config {
    protection_level = "hsm"
  }
}
```

## Schema

### Optional

- `name` (String) Name of the key to filter for
- `project_ids` (List of String) Project IDs to filter for Use '*' to list across all projects
- `protection_level` (String) Protection level of the key to filter for (software, hsm)
- `regions` (List of String) Regions to filter for Use '*' to list from all regions
- `scheduled_for_deletion` (Boolean) Filter keys by deletion status
- `tags` (List of String) Tags to filter for
- `usage` (String) Usage of the key to filter for (symmetric_encryption, asymmetric_encryption, asymmetric_signing, key_encapsulation)
