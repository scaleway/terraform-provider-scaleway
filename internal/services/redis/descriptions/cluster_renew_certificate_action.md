The [`scaleway_redis_cluster_renew_certificate`](https://registry.terraform.io/providers/scaleway/scaleway/latest/docs/actions/redis_cluster_renew_certificate) action renews the TLS certificate of a Redis™ cluster.

Renewing a certificate means you will not be able to connect using the previous certificate. Download and update the new certificate for all database clients.

Refer to the Redis [documentation](https://www.scaleway.com/en/docs/managed-databases-for-redis/) and [API documentation](https://www.scaleway.com/en/developers/api/managed-databases-for-redis/) for more information.
